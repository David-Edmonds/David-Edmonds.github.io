Startup operations.
Seven connected views.

A monthly operating review for a fictional startup: measure service health, understand product and acquisition activity, and reconcile changes in recurring revenue.

Download Tableau workbook ↓Explore seven dashboards ↓Open interactive Tableau view ↗

Editable packaged workbook with both data extracts included. The previews below are static screenshots captured in Tableau, with cursor cleanup for presentation; interactive controls are available in the downloaded workbook.

THE QUESTION

What changed this month, what explains it, and which operational signals deserve attention?

THE APPROACH

21 headline metrics with comparisons, 14 trend charts and 14 detail panels, using a shared reporting-month selector.

THE DATA

184 daily records, 26 releases and eight resolved incidents. All data is fictional, covering March–August 2026.

Definitions that keep the analysis honest

Reconcile movements

Opening-to-ending MRR and waitlist movements balance. Ending balances are not summed across days; rates divide aggregated counts. Monthly headline reconciliation checked 126 sample values.

Separate different measures

MRR is a recurring run rate; receipts are cash collection. Waitlist throughput is not cohort conversion. Frontend metrics are daily p75 observations, not monthly percentiles or a 28-day Core Web Vitals assessment.

Make comparison explicit

Rates use percentage-point changes. March has no prior-month baseline in the sample. Full-period views distinguish period totals from ending observations.

Use the workbook

  1. Download and open the packaged workbook in Tableau.
  2. Choose one of the seven dashboard tabs and change Reporting month. Cards and detail follow the selection; trends retain all six months.
  3. Use presentation mode for the full desktop layout. Supporting worksheets remain editable.

All seven dashboards were inspected in Tableau. This is a demonstration template, with no live feeds, automatic refresh or alerts. Supporting detail is precomputed: changing production data requires rebuilding both extracts together and reconciling the results. The download does not include the refresh toolkit, and real-data replacement has not been validated.
