- Downloadable professional resume

## Updating the portfolio

Website content lives in `app/`. The public GitHub Pages export lives in `docs/`.

```bash
npm install
npm run dev
npm run build
```

Only public, synthetic, or properly sanitized project materials belong in this repository. Never commit client data, federal contract-sensitive information, PII, credentials, or confidential source files.
