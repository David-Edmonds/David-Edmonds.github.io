# Product Roadmap

## Phase 1 — Truthful, testable portfolio foundation

- Preserve and accurately label Confia Solutions, LLC as David's current employer
- Make GitHub Pages the canonical public URL
- Add a browser-only CSV quality checker
- Improve tests so fabricated employment and unsafe portfolio files are caught
- Add CI, security guidance, and Codex repository instructions
- Publish an updated resume that includes Confia Solutions, independent projects, and verified prior experience

## Phase 2 — Turn the portfolio into a lead and job engine

- Add privacy-respecting site analytics
- Add a structured contact/project intake form with spam protection
- Add a dedicated Federal Contracting Performance case-study page
- Add downloadable one-page project briefs
- Add a custom domain after the canonical host is stable
- Add automated broken-link and accessibility checks

## Phase 3 — Analytics Lab product

- Add Excel support after a privacy and dependency review
- Add downloadable HTML/PDF profiling reports
- Add basic distributions and outlier flags for numeric fields
- Add explicit data dictionaries and KPI suggestions
- Keep calculations deterministic; use AI only for optional explanations
- Add server-side accounts or storage only when there is a validated user need

## Phase 4 — Social content operating system

- Create one content database for grow_goodness, CultureRankHQ, and future brands
- Track idea, asset, caption, channel, approval, due date, scheduled date, and published URL
- Use Buffer for supported publishing
- Add a lightweight dashboard only after the Airtable/Buffer workflow is stable
- Add performance reporting and weekly content recommendations

## Phase 5 — Reusable application platform

- Extract shared UI and analytics components
- Add Supabase only for features needing authentication, database records, or file storage
- Add Vercel only if a standard Next.js deployment offers a concrete advantage over the current Sites stack
- Evaluate a ChatGPT app only after the standalone tool has real users and a clear action inside ChatGPT
