# Rooted Together

Open https://david-edmonds.github.io/rooted-together/ and choose David or Becca. No account, personal link, or access code is required. The selection connects that section's progress, readiness, shared answer and comments automatically.

This is a public website. Anyone with its address can open either section and view or change shared progress, answers, meeting suggestions and comments. The selected role is a section choice, not verified identity. Personal plans, preparation and journal notes remain in browser storage with backup/import; they are not automatically shared.

Each section has an independently versioned shared answer. Comments append with retry-safe IDs, and Together refreshes every few seconds while open. Completion can save pending locally when offline and sync when the section reconnects. Existing progress and notes are preserved.

GitHub Pages serves the static app; the existing service persists shared records. Production explicitly enables section access with READING_ACCESS=sections. Legacy bearer links remain compatible with old cached clients but are never required by the current app. The release workflow generates docs/rooted-together from public/rooted-together.
