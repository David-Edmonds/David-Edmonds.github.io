# Rooted Together

Open https://david-edmonds.github.io/rooted-together/ and choose David or Becca. No account, personal link, or access code is required. The selection connects that section’s progress, readiness, published answer and comments.

Together follows Read together → Reflect & share → Talk it through → Keep what matters. There is one question editor. Drafts save locally and publish only after Share my answer; editing, polling, refreshing and reconnecting do not publish them. A later draft leaves the previously shared answer visible until Share updated answer or Remove my shared answer. Removing the published copy keeps the local draft. Earlier preparation and imported question notes become unpublished drafts.

This is a public website. Anyone with its address can open either section and view or change shared progress, published answers, meeting suggestions and posted comments. The selected role is a section choice, not verified identity. Drafts, personal plans and journal notes remain in browser storage with backup/import.

Each section has an independently versioned shared answer. Comments append only after Post comment with retry-safe IDs, and Together refreshes every few seconds while open. Completion can save pending locally when offline and sync when the section reconnects. Existing progress and notes are preserved.

GitHub Pages serves the static app; the existing service persists shared records. Production explicitly enables section access with READING_ACCESS=sections. The answers API requires a share/unshare intent marker, rejecting older automatic publication clients before writing. Legacy bearer links remain compatible with older progress clients but are never required by the current app. The release workflow generates docs/rooted-together from public/rooted-together.

The seven daily messages, all fourteen personal readings, prompts and prayers use everyday conversational wording. Day 1 explains both errors in Lewis’s observation before applying it; Day 5 and Day 7 introduce the authors’ ideas without referring to an unexplained quotation. Scripture references and source quotations remain unchanged.
