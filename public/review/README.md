# Self-guided portfolio review

The direct `/review/` page lets reviewers attempt three portfolio tasks and download their answers as a text file. It is excluded from indexing through a robots meta tag and is not linked from the main navigation. This is a public link, not access-controlled content.

Responses are held only in the open tab. There is no storage, backend submission or analytics collection. Reviewers send the downloaded text file back manually. Never commit completed responses or reviewer contact details.

The review measures self-reported usability. It does not establish observed task completion, timing, conversion rates or client outcomes. The owner assesses returned answers against the actual project evidence.

Validation covers exported files, noindex, form labels and absence of network or storage APIs. Browser checks should verify mobile layout, a partial-answer download and clearing answers on refresh.
